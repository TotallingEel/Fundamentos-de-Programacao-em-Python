<h1> Fundamentos de Programação em Python </h1>
<br>

Este repositório funciona como o meu diário de bordo online, criado para centralizar, versionar e acompanhar a evolução dos meus estudos e códigos em Python.

O objetivo principal não é buscar a perfeição absoluta de código logo de início, mas sim documentar o meu progresso prático na programação procedural e na resolução de problemas computacionais.

📂 Organização do Repositório

Evolução de Linguagens: Este repositório foca-se atualmente em **Python**, dividindo espaço com o meu estudo em **C** e o (esquecível) **JavaScript** — mantendo o malabarismo entre estudar estas três linguagens e garantir tempo para a rotina gamer

Projetos e Algoritmos: Abriga scripts desenvolvidos do zero — desde lógica procedural básica até implementações matemáticas aplicadas (como manipulação de matrizes e algoritmos lineares).

🛠️ Ferramentas e Metodologia

**Prática Diária:** Resolução de exercícios e consolidação de lógica através de plataformas interativas como o **App Mimo**.
